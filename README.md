# octojaTask
Eine Web Anwendung in React, mit einer C# API und einer postgres Datenbank. Es geht um eine Kunden - Ansprechpartner Administration. Es soll die Möglichkeit geben Kunden anzulegen und zu bearbeiten, sowie Ansprechpartner anzulegen und zu bearbeiten. Kunde zu Ansprechpartner ist 1:N Beziehung.
